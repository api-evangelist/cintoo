# Cintoo

> Cintoo is a cloud-based reality-capture and digital-twin platform that turns 3D laser-scan point-cloud data into high-fidelity, streamable 3D meshes in the cloud. Teams in AEC (architecture, engineering, construction), BIM, GIS, and asset management use Cintoo Cloud to store, visualize, classify, annotate, and share scan data and to run scan-to-BIM and digital-twin workflows. The Cintoo Open API 2.0.0 exposes accounts, users, groups, roles, projects, work zones, files, annotations, crops, measurements, tags, share links, and integrations (Autodesk, Konekt).

## API
- [Cintoo Open API 2.0.0 (OpenAPI 3.0.3)](https://aec.cintoo.com/api/2/openapi.json): 100 operations across 21 resource groups; JWT Bearer / OAuth2 authorization-code. Base URLs https://aec.cintoo.com/api/2/ and https://eu.cintoo.cloud/api/2/ (BETA).
- [API documentation](https://aec.cintoo.com/api/2)
